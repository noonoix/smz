# ARM 2.8.2 — Async Sound

1. فایل خصوصی `ams_key.h` فعلی خودتان را کنار این فایل‌ها نگه دارید؛ آن را با نمونه جایگزین نکنید.
2. `ams_board28.ino` را در Arduino IDE باز کنید.
3. Board را `Arduino Leonardo` انتخاب و Pro Micro را پروگرام کنید.
4. پاسخ `HVER` باید شامل `2.8.2|REL=1|ASND=1` باشد.

این نسخه هنگام حرکت Mouse صدا را غیرمسدودکننده پایش می‌کند و در Detection حرکت را پیش از اجرای F متوقف می‌کند.
