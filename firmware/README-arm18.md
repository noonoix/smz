# فرم‌ور بازو ۱.۸ — فیکس «کلیک/اسکرول → وسط مانیتور» (۲۰۲۶-۰۹-۰۸)

## ریشه (با مدرک از سورس HID-Project)
کتابخانه‌ی HID-Project در **هر گزارش دکمه/غلتک، محورهای ذخیره‌شده‌اش را دوباره می‌فرستد**
(`press/release → buttons() → moveTo(xAxis, yAxis, 0)`). آن محورها در بوت `(0,0)` هستند
و روی محور علامت‌دار، ۰ یعنی **وسط صفحه**. ردیاب پیکسلی فرم‌ور (`g_curX/g_curY`) از
گوشه‌ی بالا-چپ شروع می‌شد و هرگز به کتابخانه تزریق نمی‌شد ← هر کلیک/اسکرولِ بدونِ
حرکت قبلیِ بردمحور، موس را به مرکز مانیتور می‌برد. MWHEEL هم با `move(0,0,d)` دقیقاً
همین را می‌کرد.

دو باگ هم‌خانواده هم پیدا و فیکس شدند: `MMOVE|…,rel` و `MDRAG` دلتا را به‌جای پیکسل با
**واحد محور** اعمال می‌کردند (±۱۲۷ از ۳۲۷۶۷ ≈ ۷ پیکسل!).

## تغییرات ۱.۷ ← ۱.۸
- ردیاب از **مرکز** بوت می‌شود (هم‌راستا با نشانگر بوتِ ویندوز).
- `cursor_sync()` قبل از هر گزارش دکمه/غلتک (MCLICK, MDOWN, MUP, MDRAG، و کلیک مسلح TRGSND).
- MWHEEL حالا محورهای ردیابی‌شده + دلتای غلتک را می‌فرستد.
- rel-MMOVE و MDRAG پیکسلی شدند (از مسیر ردیابی‌شده‌ی `mouse_move_abs`).

## سه لایه‌ی فیکس کامل
1. **این فرم‌ور (بازو ۱.۸)** — بهداشت سمت برد.
2. **`patch_bridge_60e.py` (v2)** — روی `bridge.py` ریلیز، همین حالا قابل اجرا.
3. **`patch-v0.9.61.py`** — برای Claude Code روی ریپو: اپ قبل از کلیک/اسکرول، نشانگرِ واقعی را سینک می‌کند
   (این همان چیزی است که «کلیک جایی که موس می‌بینی» را حتی وقتی با دست جابه‌جاش کرده‌ای درست می‌کند).

## کامپایل و فلش
1. Arduino IDE ← `ams_board18.ino` را باز کن (همان board def سفارشیِ ۱.۷).
2. Sketch ← Export Compiled Binary ← فایل `ams_board18.ino.arduino_leonardo.hex` ساخته می‌شود.
3. `python isp_flash_app.py --port COMx --hex ams_board18.ino.arduino_leonardo.hex`
   (COMx = پورت برد پروگرمر؛ همان مسیر ISP ۱.۷ — سیم RST پروگرمر را بعد از فلش جدا کن).
4. نوار وضعیت اپ باید FW 1.8 نشان دهد.

## اعتبارسنجی این‌طرف
- ژنراتور anchored (`tools/make_arm18.py`) + توازن آکولاد/پرانتز برابر مبنا + هر ۵ نقطه‌ی cursor_sync حاضر.
- مدل رفتاری پایتونی (`sim/sim_arm18.py`): **۱۳/۰** — بازتولید باگ ۱.۷ + اثبات invariant در ۱.۸
  (هیچ گزارش دکمه/غلتکی هرگز محورِ غیرردیابی‌شده ندارد) + فیکس پیکسلی rel/MDRAG.
- `patch-v0.9.61.py` روی کپی ریپو تست شد: اعمال + idempotent + bridge کامپایل می‌شود + تعادل آکولاد دست‌نخورده.
- تست‌های bridge: **۲۰/۰** (شامل تست worker-level برای ack محلی MMOVE).

## تست روی سخت‌افزار
1. فلش ۱.۸ ← پلن با Mouse Move + Click: کلیک همان‌جا اتفاق می‌افتد.
2. استپ Scroll: اسکرول کار می‌کند و موس دیگر به مرکز نمی‌پرد.
3. (بعد از ریلیز v0.9.61 اپ) کلیک دقیقاً روی نشانگرِ فعلی، حتی بدون هیچ حرکت قبلی.
