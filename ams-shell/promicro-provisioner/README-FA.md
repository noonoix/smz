# Pro Micro Provisioner
ابزار مستقل ویندوز برای ATmega32U4 Pro Micro 5V/16MHz. برنامه هویت آموزشی تصادفی می‌سازد، ARM 2.8.2 را با `ams_key.h` محلی کامپایل می‌کند، ArduinoISP را با handshake واقعی STK500 پیدا می‌کند، یک‌بار erase انجام می‌دهد و سپس Application و Caterina سفارشی را می‌نویسد و Verify می‌کند.

`ams_key.h` عمداً در مخزن نیست و باید هنگام اجرا انتخاب شود. VID/PIDهای آزمایشی برای استفاده خصوصی کلاس هستند.

## کلید ثابت
پس از Extract کردن بسته Portable، فایل خصوصی را با نام دقیق `ams_key.h` در مسیر `firmware\arm28\ams_key.h` قرار دهید. برنامه هنگام اجرا آن را خودکار شناسایی می‌کند؛ دکمه انتخاب فایل فقط برای Override است.

## تمام پکیج اصلی ARM 2.8.2
تمام فایل‌های سورس، مستندات و دو HEX مرجع اصلی در `firmware/arm28` نگهداری می‌شوند. فایل واقعی `ams_key.h` تنها موردی است که عمداً در Git نیست و کاربر آن را پس از Extract کنار بقیه فایل‌ها قرار می‌دهد. برنامه HEX مرجع را خودکار فلش نمی‌کند؛ Application را از سورس کامل و کلید کاربر دوباره می‌سازد.

### روش ساده کلید
در نسخه Portable فقط `ams_key.h` را داخل پوشه `PUT-KEY-HERE` بیندازید. برنامه این مسیر را قبل از هر مسیر دیگری بررسی می‌کند و کلید را خودکار انتخاب می‌کند.
