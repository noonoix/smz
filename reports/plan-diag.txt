   13| #   * The Pro Micro arm is pumped EVERY loop iteration: its EVT| lines stream to the PC
   14| #     live and its small TX buffer can never fill up and wedge the arm.
   15| #   * Mouse commands are fire-and-ack (forwarded to the arm, OK answered at once) so dense
   16| #     human paths stay smooth; sound/SETRES still wait for the arm's real reply.
   17| #   * The keyboard ALWAYS runs on this Pico: KBDPICO| and the legacy arm keyboard envelope
   18| #     are both consumed locally - the arm never types.
   19| #   * Fixed keypad: GP4->GND = Num Lock = Start/Stop, GP3->GND = Scroll Lock = Pause/Resume.
   20| #     Both drive the standalone engine AND send the HID key to the PC.
   21| #   * Safe default: boot never starts the macro. The standalone engine waits for GP4
   22| #     (Num Lock) unless AUTOSTART below is explicitly True, and stays silent for 3 s after
   23| #     the last host command so host-driven runs never double-fire the armed states.
   24| #
