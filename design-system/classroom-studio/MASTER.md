# Classroom Studio UI system

## Direction
Compact professional desktop control surface: dark, calm, technical, and task-first.
Variance 3/10 · Motion 2/10 · Density 9/10.

## AutoCycle section
- Keep only the two export actions visible in the normal Play Options state.
- Put Resume Essentials and Schedule in one collapsed-by-default “AutoCycle settings” expander.
- Keep the two export actions on one right-aligned WrapPanel row: Plan first, Firmware second.
- Use compact fixed-width desktop buttons; never stretch action buttons across the editor.
- Explain overwrite behavior beside the export actions, not in a remote dialog.
- Dense desktop override: action height 34 px and numeric-input height 32 px.
- RTL Persian reading order; Latin protocol names remain intact.

## Tokens
- Surface: `#292C33`
- Raised/input surface: `#333740`
- Border: `#444A55`
- Primary accent: `#5E9FE8`
- Primary soft surface: `#263A52`
- Primary text: `#F5F7FA`
- Secondary text: `#B5BBC5`
- Positive/hardware-ready: `#72BC8F`
- Card radius: 8 px; inner radius: 5–6 px
- Spacing scale: 3, 6, 8, 10, 16

## Accessibility
- Never encode readiness or step order with color alone; retain labels and numbers.
- Keep keyboard focus behavior supplied by WPF controls.
- All primary controls have visible labels, tooltips, and keyboard focus behavior.
- Compact sizing is reserved for this mouse-and-keyboard desktop editor; no touch UI claim is made.
- Normal text and boundaries target WCAG AA contrast in the dark theme.
